# Definition of Done

- [ ] At least 20 calibration images captured.
- [ ] Camera matrix and distortion coefficients saved.
- [ ] Reprojection error reported.
- [ ] At least 70 original object images collected and annotated.
- [ ] 70/20/10 split list committed before training or implementation.
- [ ] Segmentation model trained and required metrics reported.
- [ ] Single-command pipeline performs undistortion, segmentation, reference detection, and measurement.
- [ ] Pipeline outputs overlay, width, height in mm, and confidence.
- [ ] Missing object or reference is handled safely.
- [ ] At least 10 physical instances measured and compared.
- [ ] MAE and mean percentage error reported.
- [ ] Raw versus undistorted measurement errors compared.
- [ ] One failure condition tested and unreliable measurements refused.
- [ ] README and decision record completed.
- [ ] Demo recorded and submission PR created.
